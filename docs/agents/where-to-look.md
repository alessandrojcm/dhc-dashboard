Schemas map `club_activity*` persistence vocab; context/controllers return Workshop-vocabulary DTOs. |
| Add Phoenix Inventory Category slice | `apps/phoenix/lib/dhc/inventory.ex` (context) + `apps/phoenix/lib/dhc/inventory/equipment_category.ex` (schema) + `apps/phoenix/lib/dhc/inventory/json_array.ex` (custom jsonb-array type) + `apps/phoenix/lib/dhc_web/controllers/inventory_categories_controller.ex` + `inventory_categories_json.ex` | NEW — ALE-105. | Add Phoenix Inventory Container slice | `apps/phoenix/lib/dhc/inventory.ex` (container context fns) + `apps/phoenix/lib/dhc/inventory/container.ex` (Ecto schema) + `apps/phoenix/lib/dhc_web/controllers/inventory_containers_controller.ex` + `inventory_containers_json.ex` | NEW — ALE-106. Phoenix owns item CRUD, history, movement, and maintenance. Svelte consumes these operations through `@dhc/api-client`; the legacy `ItemService` and `HistoryService` have been removed. |

| Add Phoenix auth (session or Discord) endpoint | `apps/phoenix/lib/dhc_web/controllers/auth_session_controller.ex` + `auth_session_json.ex` + `apps/phoenix/lib/dhc_web/plugs/require_session.ex` + `apps/phoenix/lib/dhc_web/plugs/magic_link_rate_limit.ex` + `apps/phoenix/lib/dhc/auth.ex` (context) + `apps/phoenix/lib/dhc/auth/principal.ex` + `apps/phoenix/lib/dhc/auth/principal_token.ex` + `apps/phoenix/lib/dhc/auth/external_identity.ex` | ALE-165/ALE-167. Phoenix owns magic-link, Assent Discord OAuth, and DB-backed opaque sessions. Discord starts at `GET /api/auth/discord`; callbacks resolve the immutable provider subject before considering verified-email auto-linking. The `:authenticated_session_api` pipeline uses `RequireSession`; the `:magic_link_request_api` pipeline is public + rate-limited; `:discord_oauth_api` fetches the OAuth state session. |
| Rehearse auth migration M1 | `apps/phoenix/lib/dhc/auth_migration/m1.ex` + migrations `20260720100000`–`20260720100002` + `apps/phoenix/test/dhc/auth/m1_rehearsal_test.exs` + `docs/auth-m1-rehearsal.md` | ALE-166. Additive Principal/Discord External Identity population with UUID preservation, aggregate-only audit evidence, hard anomaly gates, and rollback. Does not repoint application FKs (M2/ALE-163). |
| Run/rehearse Phoenix auth cutover M2 | `apps/phoenix/lib/dhc/auth_migration/m2.ex` + migration `20260721100000_ale_163_m2_cut_over_authentication_authority.exs` + `apps/phoenix/test/dhc/auth/m2_cutover_rehearsal_test.exs` + `docs/auth-m2-cutover-runbook.md` | ALE-163. Production recovery after committed writes restores the backup; migration rollback is for isolated rehearsal. |
| Add dashboard auth seam (SvelteKit) | `src/hooks.server.ts` + `src/lib/server/auth.ts` + `src/lib/server/roles.ts` + `src/app.d.ts` + `src/lib/server/api-client.ts` + `src/routes/auth/` + `src/routes/auth/magic-link/+page.server.ts` | NEW — ALE-164. The dashboard authenticates through the Phoenix `_dhc_session` cookie. `getPhoenixSession(cookies)` forwards the cookie to Phoenix `GET /api/auth/session`. `App.Locals.session` is the Phoenix projection `{ principal: { id, email }, roles }` — no Supabase client, JWT, or `access_token`. `apiClientOptions(cookies)` forwards the cookie for SSR/server-load/remote-function calls; the browser uses `configureClient({ credentials: "include" })`. |
